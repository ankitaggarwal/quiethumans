# Quiet Humans — slide deck

An animated HTML deck for **Quiet Humans**:
a local-first search engine for indie makers (local Gemma + EmbeddingGemma + Qdrant on a Mac).

## Use
- Open `index.html` (served, not `file://` — it fetches slide fragments).
- Navigate: arrow keys / spacebar / click. `F` = fullscreen.
- 22 slides, scales to any window (1280×720 canvas).
